# Photo date and geo information easy edition

## App main focus
- Interface to help me edit geo information and time information about a photo

## Tech stack
- Go would be my prefered stack
- lower layer as possible
- Fast at work and easy to lauch

# How it works
- I drag a folder into the app
- It analyse the photos inside it (mainly jpg, but could be HEIC)
- there is a view, wehre i can see all the pictures at ones, add them to a group (like a basket)
- Then i can batch edit the basket selection and attribute a geo location and a date
- as I will be using this tool to batch edit old photos, I would like the time selection to allow only a year (and you'll store 01-01-1996:000000 for 1996 selection). Something like starting with a decade, then allow to select a year then a month then a day, then an hour. But I can stop at each step.
- For editing geolocation, you can display me a map (i can give you mapbox API key for instance). And I can click on the map in order to give you the point.
- when I finish the time and location selection, the app edit the EXIF information
